# Changelog

## 1.1.0

First public InputFX release.

- Native keyboard and mouse capture with automatic rendering over scene output.
- Transparent cyberpunk keycaps, mouse-action badges, and animated cursor rings.
- Color pickers and transparency, size, timing, and position controls.
- Cursor mapping through Window Capture and Display Capture transforms.
- Optional visibility hotkey and automatic migration from earlier Cyber Input settings.
- Corrected rendering order so opaque sources cannot cover the effects.
